PetMeta website source snapshot - 9 November 2026

Includes consumer website, business and Rider web screens, public assets, backend source, scripts and configuration.

Setup: install Node.js 20+, run npm ci, copy .env.example to .env.local and configure services, then npm run dev.
See WEBSITE-SETUP.md and docs/rider/README.md. Rider Android project/APKs are separate and not included in this website archive.

Private environment files, installed dependencies, local application data and build output are excluded. Existing website video assets are included as part of the consumer website source.
